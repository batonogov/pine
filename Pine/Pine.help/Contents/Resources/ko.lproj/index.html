Pine 도움말

macOS에서 프로젝트, 코드, 터미널 및 Git에 집중할 수 있는 네이티브 편집기입니다.

시작하기

1. 폴더 열기

파일 > 폴더 열기를 선택한 다음 프로젝트가 있는 디렉토리를 선택합니다.

2. 파일 열기

사이드바에서 파일을 선택하거나 빠른 열기로 이름을 검색합니다.

3. 작업 공간 배치하기

탭을 편집기 가장자리로 드래그하여 패널을 분할하거나 다른 탭 막대로 드래그하여 이동합니다.

4. 작업 이어가기

Pine은 다시 실행할 때 프로젝트 윈도우, 편집기 탭 및 패널 배치를 복원합니다.

필수 단축키

폴더 열기⇧⌘O
빠른 열기⌘P
기호⌘R
프로젝트에서 찾기⇧⌘F
줄로 이동⌘L
저장⌘S
터미널 표시 또는 가리기⌘`
새 터미널 탭⌘T
Markdown 미리보기⇧⌘P
Git 브랜치 전환⇧⌘B

팁: 메뉴에서 사용 가능한 모든 명령과 현재 단축키를 확인할 수 있습니다.

편집기, 패널 및 터미널

패널 분할

편집기와 터미널 탭을 같은 종류의 패널 간에 이동할 수 있습니다. 가장자리에 놓으면 새 분할이 생성됩니다.

통합 터미널

코드 옆에서 완전한 터미널을 사용합니다. 열려 있는 탭은 스크롤 기록을 유지합니다.

안전한 저장

수정된 탭은 닫기 전에 보호됩니다. 자동 저장과 저장 시 포맷은 파일 메뉴에서 설정합니다.

Git 통합

사이드바와 여백에서 변경 사항을 확인합니다. 브랜치 전환기로 로컬 브랜치를 선택합니다.

도움이 더 필요하십니까?

Pine 이슈 트래커에서 문제를 신고하거나 개선 사항을 제안하십시오.
