에이전트 받은편지함과 워크플로

에이전트 받은편지함

보기 > 에이전트 받은편지함을 선택하거나 ⇧⌘I를 눌러 열려 있는 모든 프로젝트의 작업을 확인합니다. 화살표 키로 작업을 선택하고 Return을 눌러 해당 작업의 정확한 실행 중 세션으로 돌아갑니다.

비공개 알림

설정 > 에이전트에서 입력 대기, 실패, 완료 및 프로세스 종료 이벤트 중 알림을 받을 항목을 선택합니다. 알림에는 프롬프트, 터미널 출력, 토큰, 절대 경로 또는 공급업체 식별자가 포함되지 않습니다.

복구와 워크트리

작업의 컨텍스트 메뉴에서 지원되는 공급업체 세션을 재개하거나 새 세션을 시작하거나 목표를 복사할 수 있습니다. 격리된 워크트리는 저장소 안에 유지되며 명시적인 작업으로만 정리됩니다.

완료 요약

완료된 작업은 확인된 변경 사항과 테스트 증거를 추론, 모호성 및 에이전트 보고 내용과 구분하므로 다음 작업 전에 결과를 판단할 수 있습니다.

에이전트 감지

Pine은 터미널에서 실행 중인 지원되는 CLI 에이전트를 감지하고 배지와 표시기로 상태를 보여 줍니다.

활동 패널

에이전트 활동의 실시간 보기를 확인합니다: 변경된 파일, 실행된 명령, 현재 작업 상태.

에이전트 기록

에이전트의 변경 사항을 검토하고 실행 취소합니다. 확인된 미리 보기는 적용 전에 정확히 무엇이 바뀌는지 보여 줍니다.

개인정보 보호

에이전트 컨텍스트 전달은 선택 사항이며 읽기 전용입니다. Pine은 사용자의 조작 없이는 코드나 터미널 출력을 어디로도 보내지 않습니다.

중요: Pine은 실행 중인 작업의 정확한 세대로만 이동하며 그렇지 않으면 안전하게 거부합니다. 작업 메타데이터 복원은 공급업체 세션이 재개되었다는 뜻이 아닙니다. 빠른 터미널은 아직 에이전트 감지에 포함되지 않습니다.

Pine은 정확한 실행 파일 이름으로 Pi, Codex, Claude Code, OpenCode, Copilot, Aider, Gemini, Amp, Cursor Agent, Goose, Qwen Code 및 Crush를 인식합니다. 호환성 표에 달리 명시되지 않은 경우 프로세스만 인식합니다.

CLI 에이전트 호환성 표와 현재 제한 사항을 확인합니다.
