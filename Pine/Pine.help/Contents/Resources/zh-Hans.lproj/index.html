开始使用

1. 打开文件夹

选择“文件”>“打开文件夹”，然后选择包含项目的目录。

2. 打开文件

在侧边栏选择文件，或用快速打开按名称查找。

3. 整理工作区

将标签页拖到编辑器边缘以创建分屏，或拖到其他标签栏以移动。

4. 继续工作

Pine会在您返回时恢复项目窗口、编辑器标签页和窗格布局。

编辑器、窗格与终端

分屏窗格

编辑器和终端标签页可在同类窗格之间移动。拖到边缘即可创建新的分屏。

预览与固定标签页

点击侧边栏中的文件会以临时预览标签页打开。双击或编辑即可固定它。

查找与替换

按Cmd+F在文件中查找。用Cmd+Option+F查找并替换。全项目搜索为Cmd+Shift+F。

代码折叠与小地图

点击装订线中的三角形可折叠代码块。小地图可在“显示”菜单中切换。

Markdown预览

按Cmd+Shift+P在仅源代码、渲染和并排Markdown预览之间循环切换。

符号导航

按Cmd+R跳转到当前文件中的函数、类和结构体。

安全保存

有修改的标签页在关闭前会受到保护。“自动保存”和“保存时格式化”位于“文件”菜单。

会话恢复

重新打开项目时，Pine会恢复您的标签页、窗格布局和光标位置。

终端与快速终端

集成终端

在代码旁使用完整的终端。只要标签页保持打开，滚动历史就会保留。

快速终端

按Ctrl+Option+空格切换一个悬浮在任何应用上方的下拉式终端。

可点击链接

在终端输出中按住Cmd点击“文件:行”引用即可在编辑器中打开。URL会在系统浏览器中打开。

TUI应用

Vim、htop等TUI应用可原生运行。完全支持oh-my-zsh和颜色主题。

Git集成

文件状态

侧边栏以彩色状态指示显示已修改、已添加和已删除的文件。

差异标记

新增、修改和删除的行以彩色标记显示在编辑器装订线中。

切换分支

点击标题栏中的分支名或按Cmd+Shift+B可在本地分支之间切换。

Blame视图

切换Blame视图以查看每行的提交信息：哈希、作者、时间戳和消息。

语言服务器与诊断

代码智能

Pine使用Language Server Protocol提供诊断、补全、悬停、转到定义和重命名。

配置服务器

打开“设置”>“语言”，按语言启用、禁用或配置语言服务器可执行文件。

问题面板

在可折叠面板中查看所有项目诊断。使用键盘快捷键在错误和警告之间导航。

代码操作

点击装订线中的诊断指示器或使用菜单来应用快速修复和重构。

代理感知

代理检测

Pine检测在终端中运行的受支持CLI代理，并通过徽章和指示器显示其状态。

活动面板

查看代理活动的实时视图：已更改文件、已运行命令和当前工作状态。

代理历史

查看并撤销代理更改。经过验证的预览会在应用前准确显示将要更改的内容。

隐私

代理上下文传递是可选且只读的。未经您的操作，Pine绝不会将您的代码或终端输出发送到任何地方。

设置与键绑定

设置窗口

按Cmd+逗号打开设置。配置编辑器默认值、终端、语言服务器和代理隐私。

自定义键绑定

通过受管理的键绑定文件覆盖键盘快捷键。命令面板会显示当前有效的绑定。

命令面板

通过支持模糊搜索的面板发现并运行命令，类似于VS Code。

任务

定义自定义任务，从命令面板或“任务”菜单运行 shell 命令、格式化工具或构建脚本。

疑难排查

  • 终端显示黑屏 Pine默认使用Metal渲染器。如果看到黑屏，请按住Option键重新启动，或运行defaults write io.github.batonogov.pine PINE_DISABLE_METAL -bool YES切换到CoreGraphics。
  • LSP补全或诊断不起作用 打开“设置”>“语言”并检查服务器可执行文件路径。Pine会在状态栏中报告服务器错误。
  • 大文件加载缓慢 超过1 MB的文件会提示关闭语法高亮。超过10 MB的文件会逐步加载。使用小地图浏览大文件。
  • 保存时格式化未生效 保存时格式化要求格式化工具（如terraform、shfmt、prettier）位于您的PATH中。请通过Homebrew安装。
  • macOS 26或27兼容性 Pine的目标是macOS 26（Tahoe）。如果遇到平台特定的问题，请在错误报告中附上sw_vers和xcodebuild -version的输出。
  • 未检测到代理 Pine通过进程名检测受支持的CLI代理。请确保代理在Pine终端窗格中运行。快速终端暂不支持代理检测。
