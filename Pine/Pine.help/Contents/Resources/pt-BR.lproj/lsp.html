Ajuda do Pine

Servidores de linguagem e diagnósticos

Inteligência de código

O Pine usa o Language Server Protocol para diagnósticos, autocompletar, hover, ir para definição e renomear.

Configurar servidores

Abra Ajustes > Linguagens para ativar, desativar ou configurar os executáveis do servidor de linguagem por idioma.

Painel de problemas

Veja todos os diagnósticos do projeto em um painel recolhível. Navegue por erros e avisos com atalhos de teclado.

Ações de código

Clique no indicador de diagnóstico na medianiz ou use o menu para aplicar correções rápidas e refatorações.
