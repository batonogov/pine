Primeiros passos

1. Abrir uma pasta

Escolha Arquivo > Abrir Pasta e selecione o diretório que contém o seu projeto.

2. Abrir um arquivo

Selecione um arquivo na barra lateral ou use a Abertura rápida para encontrá-lo pelo nome.

3. Organizar o espaço de trabalho

Arraste uma aba até uma borda do editor para criar uma divisão, ou para outra barra de abas para movê-la.

4. Continuar trabalhando

O Pine restaura as janelas do projeto, as abas do editor e o layout dos painéis quando você volta.

Editor, painéis e terminal

Painéis divididos

As abas do editor e do terminal podem ser movidas entre painéis do mesmo tipo. Solte em uma borda para criar uma nova divisão.

Pré-visualização e abas fixadas

Clicar em um arquivo da barra lateral abre como aba de pré-visualização temporária. Duplo clique ou edite para fixá-la.

Buscar e substituir

Pressione Cmd+F para buscar no arquivo. Use Cmd+Option+F para buscar e substituir. A busca em todo o projeto é Cmd+Shift+F.

Dobramento de código e minimapa

Clique em um triângulo da medianiz para dobrar blocos de código. Ative ou desative o minimapa no menu Visualização.

Pré-visualização de Markdown

Pressione Cmd+Shift+P para alternar entre apenas fonte, renderizado e pré-visualização de Markdown lado a lado.

Navegação por símbolos

Pressione Cmd+R para ir a funções, classes e structs no arquivo atual.

Salvamento seguro

Abas com alterações não salvas são protegidas antes de fechar. O salvamento automático e Formatar ao salvar estão disponíveis no menu Arquivo.

Restauração de sessão

O Pine restaura suas abas, o layout dos painéis e as posições do cursor ao reabrir um projeto.

Terminal e Terminal rápido

Terminal integrado

Use um terminal completo ao lado do seu código. As abas de terminal mantêm o histórico enquanto permanecem abertas.

Terminal rápido

Pressione Ctrl+Option+Espaço para alternar um terminal suspenso flutuante sobre qualquer aplicativo.

Links clicáveis

Cmd+clique em referências arquivo:linha da saída do terminal para abri-las no editor. URLs abrem no navegador do sistema.

Aplicativos TUI

Vim, htop e outros aplicativos TUI funcionam nativamente. oh-my-zsh e temas de cor são totalmente suportados.

Integração com Git

Status de arquivos

A barra lateral mostra arquivos modificados, adicionados e excluídos com indicadores coloridos de status.

Marcadores de diff

Linhas adicionadas, modificadas e excluídas aparecem como marcadores coloridos na medianiz do editor.

Troca de branch

Clique no nome do branch na barra de título ou pressione Cmd+Shift+B para alternar entre branches locais.

Visão de blame

Ative a visão de blame para ver informações de commit por linha: hash, autor, carimbo de data/hora e mensagem.

Servidores de linguagem e diagnósticos

Inteligência de código

O Pine usa o Language Server Protocol para diagnósticos, autocompletar, hover, ir para definição e renomear.

Configurar servidores

Abra Ajustes > Linguagens para ativar, desativar ou configurar os executáveis do servidor de linguagem por idioma.

Painel de problemas

Veja todos os diagnósticos do projeto em um painel recolhível. Navegue por erros e avisos com atalhos de teclado.

Ações de código

Clique no indicador de diagnóstico na medianiz ou use o menu para aplicar correções rápidas e refatorações.

Detecção de agentes

Detecção de agentes

O Pine detecta agentes CLI suportados em execução no terminal e mostra seu status com distintivos e indicadores.

Painel de atividade

Veja uma visão ao vivo da atividade do agente: arquivos alterados, comandos executados e estado atual.

Histórico de agentes

Revise e desfaça as alterações dos agentes. As pré-visualizações verificadas mostram exatamente o que mudará antes de você aplicar.

Privacidade

A entrega de contexto ao agente é opcional e somente leitura. O Pine nunca envia seu código ou a saída do terminal a lugar algum sem sua ação.

Veja a matriz de compatibilidade dos agentes CLI e as limitações atuais.

Ajustes e atalhos de teclado

Janela de ajustes

Pressione Cmd+vírgula para abrir Ajustes. Configure padrões do editor, terminal, servidores de linguagem e privacidade do agente.

Atalhos de teclado personalizados

Substitua os atalhos de teclado por meio de arquivos de atalhos gerenciados. A paleta de comandos mostra as combinações ativas.

Paleta de comandos

Descubra e execute comandos por uma paleta com pesquisa difusa, semelhante ao VS Code.

Tarefas

Defina tarefas personalizadas para executar comandos de shell, formatadores ou scripts de build pela paleta de comandos ou pelo menu Tarefas.

Solução de problemas

  • O terminal mostra uma tela preta O Pine usa um renderizador Metal por padrão. Se vir uma tela preta, reinicie mantendo a tecla option pressionada, ou execute defaults write io.github.batonogov.pine PINE_DISABLE_METAL -bool YES para mudar para CoreGraphics.
  • O autocompletar ou diagnósticos LSP não funcionam Abra Ajustes > Linguagens e verifique o caminho do executável do servidor. O Pine relata erros do servidor na barra de status.
  • Arquivos grandes estão lentos Arquivos com mais de 1 MB oferecem desativar o realce de sintaxe. Arquivos com mais de 10 MB são carregados progressivamente. Use o minimapa para navegar em arquivos grandes.
  • Formatar ao salvar não é aplicado Formatar ao salvar exige que a ferramenta de formatação (ex.: terraform, shfmt, prettier) esteja no seu PATH. Instale via Homebrew.
  • Compatibilidade com macOS 26 ou 27 O Pine tem como alvo o macOS 26 (Tahoe). Se encontrar um problema específico da plataforma, inclua a saída de sw_vers e xcodebuild -version no seu relatório de bug.
  • O agente não é detectado O Pine detecta agentes CLI suportados pelo nome do processo. Certifique-se de que o agente esteja sendo executado em um painel de terminal do Pine. O Terminal rápido ainda não oferece suporte à detecção de agentes.
