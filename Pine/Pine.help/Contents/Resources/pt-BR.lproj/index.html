Ajuda do Pine

Um editor nativo e focado para projetos, código, terminal e Git no macOS.

Primeiros passos

1. Abra uma pasta

Escolha Arquivo > Abrir Pasta e selecione o diretório que contém seu projeto.

2. Abra um arquivo

Selecione um arquivo na barra lateral ou use a Abertura Rápida para buscá-lo pelo nome.

3. Organize o espaço de trabalho

Arraste uma aba até a borda do editor para dividir um painel ou até outra barra de abas para movê-la.

4. Continue trabalhando

O Pine restaura as janelas do projeto, as abas e o layout dos painéis quando você retorna.

Atalhos essenciais

Abrir Pasta⇧⌘O
Abertura Rápida⌘P
Símbolos⌘R
Buscar no Projeto⇧⌘F
Ir para a Linha⌘L
Salvar⌘S
Mostrar ou ocultar terminal⌘`
Nova aba do terminal⌘T
Pré-visualização Markdown⇧⌘P
Trocar branch do Git⇧⌘B

Dica: os menus mostram todos os comandos disponíveis e seus atalhos atuais.

Editor, painéis e terminal

Painéis divididos

Abas do editor e do terminal podem ser movidas entre painéis compatíveis. Solte em uma borda para criar uma divisão.

Terminal integrado

Use um terminal completo ao lado do código. As abas abertas preservam o histórico de rolagem.

Salvamento seguro

Abas modificadas são protegidas antes de fechar. Salvamento Automático e Formatar ao Salvar ficam no menu Arquivo.

Integração com Git

A barra lateral e a margem mostram alterações. Use o seletor para alternar entre branches locais.
