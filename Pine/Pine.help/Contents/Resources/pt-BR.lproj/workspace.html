Ajuda do Pine

Editor, painéis e terminal

Painéis divididos

As abas do editor e do terminal podem ser movidas entre painéis do mesmo tipo. Solte em uma borda para criar uma nova divisão.

Pré-visualização e abas fixadas

Clicar em um arquivo da barra lateral abre como aba de pré-visualização temporária. Duplo clique ou edite para fixá-la.

Buscar e substituir

Pressione Cmd+F para buscar no arquivo. Use Cmd+Option+F para buscar e substituir. A busca em todo o projeto é Cmd+Shift+F.

Dobramento de código e minimapa

Clique em um triângulo da medianiz para dobrar blocos de código. Ative ou desative o minimapa no menu Visualização.

Pré-visualização de Markdown

Pressione Cmd+Shift+P para alternar entre apenas fonte, renderizado e pré-visualização de Markdown lado a lado.

Navegação por símbolos

Pressione Cmd+R para ir a funções, classes e structs no arquivo atual.

Salvamento seguro

Abas com alterações não salvas são protegidas antes de fechar. O salvamento automático e Formatar ao salvar estão disponíveis no menu Arquivo.

Restauração de sessão

O Pine restaura suas abas, o layout dos painéis e as posições do cursor ao reabrir um projeto.
