Integração com Git

Status de arquivos

A barra lateral mostra arquivos modificados, adicionados e excluídos com indicadores coloridos de status.

Marcadores de diff

Linhas adicionadas, modificadas e excluídas aparecem como marcadores coloridos na medianiz do editor.

Troca de branch

Clique no nome do branch na barra de título ou pressione Cmd+Shift+B para alternar entre branches locais.

Visão de blame

Ative a visão de blame para ver informações de commit por linha: hash, autor, carimbo de data/hora e mensagem.
