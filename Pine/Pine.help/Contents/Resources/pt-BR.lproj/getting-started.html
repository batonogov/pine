Ajuda do Pine

Primeiros passos

1. Abrir uma pasta

Escolha Arquivo > Abrir Pasta e selecione o diretório que contém o seu projeto.

2. Abrir um arquivo

Selecione um arquivo na barra lateral ou use a Abertura rápida para encontrá-lo pelo nome.

3. Organizar o espaço de trabalho

Arraste uma aba até uma borda do editor para criar uma divisão, ou para outra barra de abas para movê-la.

4. Continuar trabalhando

O Pine restaura as janelas do projeto, as abas do editor e o layout dos painéis quando você volta.
