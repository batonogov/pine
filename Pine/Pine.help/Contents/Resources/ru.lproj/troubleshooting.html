Справка Pine

Устранение неполадок

  • Терминал показывает чёрный экран Pine по умолчанию использует рендерер Metal. Если видите чёрный экран, перезапустите приложение с зажатой клавишей Option или выполните defaults write io.github.batonogov.pine PINE_DISABLE_METAL -bool YES для перехода на CoreGraphics.
  • Не работает автодополнение или диагностика LSP Откройте «Настройки» > «Языки» и проверьте путь к исполняемому файлу сервера. Pine сообщает об ошибках сервера в строке состояния.
  • Большие файлы работают медленно Для файлов больше 1 МБ предлагается отключить подсветку синтаксиса. Файлы больше 10 МБ загружаются постепенно. Используйте миникарту для навигации по большим файлам.
  • Форматирование при сохранении не применяется Для форматирования при сохранении требуется, чтобы инструмент форматирования (например, terraform, shfmt, prettier) был в вашем PATH. Установите его через Homebrew.
  • Совместимость с macOS 26 или 27 Pine ориентирован на macOS 26 (Tahoe). Если возникла проблема, специфичная для платформы, включите вывод sw_vers и xcodebuild -version в отчёт об ошибке.
  • Агент не распознан Pine распознаёт поддерживаемые CLI-агенты по имени процесса. Убедитесь, что агент запущен в панели терминала Pine. Быстрый терминал пока не поддерживает обнаружение агентов.
