Справка Pine

Сосредоточенный нативный редактор для проектов, кода, терминала и Git в macOS.

Начало работы

1. Откройте папку

Выберите «Файл» > «Открыть папку», затем укажите каталог проекта.

2. Откройте файл

Выберите файл в боковой панели или найдите его по имени через «Быстрое открытие».

3. Настройте рабочее пространство

Перетащите вкладку к краю редактора, чтобы разделить панель, или на другую строку вкладок, чтобы переместить её.

4. Продолжайте с того же места

Pine восстановит окна проекта, вкладки редактора и расположение панелей при следующем запуске.

Основные сочетания клавиш

Открыть папку⇧⌘O
Быстрое открытие⌘P
Символы⌘R
Поиск в проекте⇧⌘F
Перейти к строке⌘L
Сохранить⌘S
Показать терминал⌘`
Новая вкладка терминала⌘T
Предпросмотр Markdown⇧⌘P
Сменить ветку Git⇧⌘B

Совет: в меню показаны все доступные команды и их текущие сочетания клавиш.

Редактор, панели и терминал

Разделение панелей

Вкладки редактора и терминала можно перемещать между панелями одного типа. Перетащите вкладку к краю, чтобы создать новую панель.

Встроенный терминал

Работайте в полноценном терминале рядом с кодом. Пока вкладка открыта, история вывода сохраняется.

Безопасное сохранение

Pine защищает несохранённые вкладки при закрытии. Автосохранение и форматирование доступны в меню «Файл».

Интеграция с Git

Изменения видны в боковой панели и на полях редактора. Переключатель веток позволяет выбирать локальные ветки.
