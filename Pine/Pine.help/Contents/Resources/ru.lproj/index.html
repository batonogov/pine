Начало работы

1. Откройте папку

Выберите «Файл» > «Открыть папку», затем укажите каталог проекта.

2. Откройте файл

Выберите файл в боковой панели или найдите его по имени через «Быстрое открытие».

3. Настройте рабочее пространство

Перетащите вкладку к краю редактора, чтобы разделить панель, или на другую строку вкладок, чтобы переместить её.

4. Продолжайте с того же места

Pine восстановит окна проекта, вкладки редактора и расположение панелей при следующем запуске.

Редактор, панели и терминал

Разделение панелей

Вкладки редактора и терминала можно перемещать между панелями одного типа. Перетащите вкладку к краю, чтобы создать новую панель.

Предпросмотр и закреплённые вкладки

При щелчке по файлу в боковой панели он открывается как временная вкладка предпросмотра. Двойной щелчок или редактирование закрепляют её.

Поиск и замена

Нажмите Cmd+F для поиска в файле. Используйте Cmd+Option+F для поиска и замены. Поиск по всему проекту — Cmd+Shift+F.

Сворачивание кода и миникарта

Щёлкните по треугольнику в поле номеров строк, чтобы свернуть блоки кода. Миникарта переключается в меню «Вид».

Предпросмотр Markdown

Нажмите Cmd+Shift+P для переключения между только исходником, отображением и параллельным предпросмотром Markdown.

Навигация по символам

Нажмите Cmd+R, чтобы перейти к функциям, классам и структурам в текущем файле.

Безопасное сохранение

Pine защищает несохранённые вкладки при закрытии. Автосохранение и форматирование доступны в меню «Файл».

Восстановление сессии

Pine восстанавливает ваши вкладки, расположение панелей и позиции курсора при повторном открытии проекта.

Терминал и быстрый терминал

Встроенный терминал

Работайте в полноценном терминале рядом с кодом. Пока вкладка открыта, история вывода сохраняется.

Быстрый терминал

Нажмите Ctrl+Option+Space, чтобы вызвать плавающий выпадающий терминал поверх любого приложения.

Кликабельные ссылки

Щёлкайте с нажатым Cmd по ссылкам вида файл:строка в выводе терминала, чтобы открыть их в редакторе. URL открываются в системном браузере.

TUI-приложения

Vim, htop и другие TUI-приложения работают нативно. oh-my-zsh и цветовые темы полностью поддерживаются.

Интеграция с Git

Статус файлов

Боковая панель показывает изменённые, добавленные и удалённые файлы с цветными индикаторами статуса.

Метки изменений

Добавленные, изменённые и удалённые строки отображаются как цветные метки в поле редактора.

Переключение веток

Щёлкните имя ветки в строке заголовка или нажмите Cmd+Shift+B для переключения между локальными ветками.

Режим blame

Включите режим blame, чтобы видеть информацию о коммите построчно: хеш, автор, время и сообщение.

Языковые серверы и диагностика

Интеллектуальная работа с кодом

Pine использует Language Server Protocol для диагностики, автодополнения, подсказок при наведении, перехода к определению и переименования.

Настройка серверов

Откройте «Настройки» > «Языки», чтобы включать, отключать или настраивать исполняемые файлы языковых серверов для каждого языка.

Панель проблем

Просматривайте всю диагностику проекта в сворачиваемой панели. Перемещайтесь по ошибкам и предупреждениям с помощью сочетаний клавиш.

Кодовые действия

Щёлкните индикатор диагностики в поле номеров или используйте меню, чтобы применить быстрые исправления и рефакторинг.

Распознавание агентов

Обнаружение агентов

Pine распознаёт поддерживаемые CLI-агенты, запущенные в терминале, и показывает их статус с помощью значков и индикаторов.

Панель активности

Просматривайте активность агентов в реальном времени: изменённые файлы, выполненные команды и текущее состояние.

История агентов

Просматривайте и отменяйте изменения агентов. Проверенные предпросмотры показывают точно, что изменится перед применением.

Конфиденциальность

Передача контекста агенту необязательна и доступна только для чтения. Pine никогда не отправляет ваш код или вывод терминала куда-либо без вашего действия.

Pine распознаёт Pi, Codex, Claude Code, OpenCode, Copilot, Aider, Gemini, Amp, Cursor Agent, Goose, Qwen Code и Crush по точному имени исполняемого файла. Если в матрице не указано иное, распознаётся только процесс.

Откройте матрицу совместимости CLI-агентов и список текущих ограничений.

Настройки и привязки клавиш

Окно настроек

Нажмите Cmd+запятая, чтобы открыть «Настройки». Настройте параметры редактора, терминала, языковых серверов и конфиденциальность агентов.

Пользовательские привязки клавиш

Переопределяйте сочетания клавиш через управляемые файлы привязок. Палитра команд показывает действующие сочетания.

Палитра команд

Находите и запускайте команды через палитру с нечётким поиском, подобную VS Code.

Задачи

Определяйте пользовательские задачи, чтобы запускать команды оболочки, форматтеры или скрипты сборки из палитры команд или меню «Задачи».

Устранение неполадок

  • Терминал показывает чёрный экран Pine по умолчанию использует рендерер Metal. Если видите чёрный экран, перезапустите приложение с зажатой клавишей Option или выполните defaults write io.github.batonogov.pine PINE_DISABLE_METAL -bool YES для перехода на CoreGraphics.
  • Не работает автодополнение или диагностика LSP Откройте «Настройки» > «Языки» и проверьте путь к исполняемому файлу сервера. Pine сообщает об ошибках сервера в строке состояния.
  • Большие файлы работают медленно Для файлов больше 1 МБ предлагается отключить подсветку синтаксиса. Файлы больше 10 МБ загружаются постепенно. Используйте миникарту для навигации по большим файлам.
  • Форматирование при сохранении не применяется Для форматирования при сохранении требуется, чтобы инструмент форматирования (например, terraform, shfmt, prettier) был в вашем PATH. Установите его через Homebrew.
  • Совместимость с macOS 26 или 27 Pine ориентирован на macOS 26 (Tahoe). Если возникла проблема, специфичная для платформы, включите вывод sw_vers и xcodebuild -version в отчёт об ошибке.
  • Агент не распознан Pine распознаёт поддерживаемые CLI-агенты по имени процесса. Убедитесь, что агент запущен в панели терминала Pine. Быстрый терминал пока не поддерживает обнаружение агентов.
