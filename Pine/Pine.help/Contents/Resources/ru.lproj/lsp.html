Справка Pine

Языковые серверы и диагностика

Интеллектуальная работа с кодом

Pine использует Language Server Protocol для диагностики, автодополнения, подсказок при наведении, перехода к определению и переименования.

Настройка серверов

Откройте «Настройки» > «Языки», чтобы включать, отключать или настраивать исполняемые файлы языковых серверов для каждого языка.

Панель проблем

Просматривайте всю диагностику проекта в сворачиваемой панели. Перемещайтесь по ошибкам и предупреждениям с помощью сочетаний клавиш.

Кодовые действия

Щёлкните индикатор диагностики в поле номеров или используйте меню, чтобы применить быстрые исправления и рефакторинг.
