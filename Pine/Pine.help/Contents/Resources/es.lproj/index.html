Primeros pasos

1. Abrir una carpeta

Elige Archivo > Abrir carpeta y selecciona el directorio que contiene tu proyecto.

2. Abrir un archivo

Selecciona un archivo en la barra lateral o usa Apertura rápida para encontrarlo por nombre.

3. Organizar el espacio de trabajo

Arrastra una pestaña a un borde del editor para crear una división, o a otra barra de pestañas para moverla.

4. Continuar trabajando

Pine restaura las ventanas del proyecto, las pestañas del editor y la distribución de paneles al volver.

Editor, paneles y terminal

Paneles divididos

Las pestañas de editor y terminal pueden moverse entre paneles del mismo tipo. Suelta en un borde para crear una nueva división.

Vista previa y pestañas fijadas

Al hacer clic en un archivo de la barra lateral se abre como pestaña de vista previa temporal. Doble clic o editar para fijarla.

Buscar y reemplazar

Pulsa Cmd+F para buscar en el archivo. Usa Cmd+Option+F para buscar y reemplazar. La búsqueda en todo el proyecto es Cmd+Shift+F.

Plegado de código y minimapa

Haz clic en un triángulo del canal para plegar bloques de código. Activa o desactiva el minimapa desde el menú Visualización.

Vista previa de Markdown

Pulsa Cmd+Shift+P para alternar entre solo fuente, renderizado y vista previa de Markdown en paralelo.

Navegación por símbolos

Pulsa Cmd+R para saltar a funciones, clases y structs del archivo actual.

Guardado seguro

Las pestañas con cambios sin guardar se protegen antes de cerrarse. El autoguardado y Formatear al guardar están disponibles en el menú Archivo.

Restauración de sesión

Pine restaura tus pestañas, la distribución de paneles y las posiciones del cursor al reabrir un proyecto.

Terminal y Terminal rápido

Terminal integrado

Usa un terminal completo junto a tu código. Las pestañas de terminal conservan su historial mientras permanecen abiertas.

Terminal rápido

Pulsa Ctrl+Opción+Espacio para mostrar u ocultar un terminal desplegable flotante sobre cualquier aplicación.

Enlaces clicables

Cmd+clic en referencias archivo:línea de la salida del terminal las abre en el editor. Las URLs se abren en el navegador del sistema.

Aplicaciones TUI

Vim, htop y otras aplicaciones TUI funcionan de forma nativa. oh-my-zsh y los temas de color son totalmente compatibles.

Integración con Git

Estado de archivos

La barra lateral muestra archivos modificados, añadidos y eliminados con indicadores de estado de color.

Marcadores de diff

Las líneas añadidas, modificadas y eliminadas aparecen como marcadores de color en el canal del editor.

Cambio de rama

Haz clic en el nombre de la rama en la barra de título o pulsa Cmd+Shift+B para cambiar entre ramas locales.

Vista de blame

Activa la vista de blame para ver la información de commit de cada línea: hash, autor, marca de tiempo y mensaje.

Servidores de lenguaje y diagnósticos

Inteligencia de código

Pine usa el Language Server Protocol para diagnósticos, completado, hover, ir a definición y renombrado.

Configurar servidores

Abre Ajustes > Lenguajes para activar, desactivar o configurar los ejecutables del servidor de lenguaje para cada idioma.

Panel de problemas

Consulta todos los diagnósticos del proyecto en un panel plegable. Navega por errores y advertencias con atajos de teclado.

Acciones de código

Haz clic en el indicador de diagnóstico del canal o usa el menú para aplicar correcciones rápidas y refactorizaciones.

Detección de agentes

Detección de agentes

Pine detecta los agentes CLI compatibles que se ejecutan en el terminal y muestra su estado con distintivos e indicadores.

Panel de actividad

Consulta una vista en vivo de la actividad del agente: archivos modificados, comandos ejecutados y estado actual.

Historial de agentes

Revisa y deshaz los cambios de los agentes. Las vistas previas verificadas muestran exactamente qué cambiará antes de aplicarlo.

Privacidad

La entrega de contexto del agente es opcional y de solo lectura. Pine nunca envía tu código ni la salida del terminal a ningún sitio sin tu acción.

Consulta la matriz de compatibilidad de agentes CLI y sus limitaciones actuales.

Ajustes y combinaciones de teclas

Ventana de ajustes

Pulsa Cmd+coma para abrir Ajustes. Configura los valores predeterminados del editor, el terminal, los servidores de lenguaje y la privacidad del agente.

Combinaciones de teclas personalizadas

Sobrescribe los atajos de teclado mediante archivos de combinaciones gestionados. La paleta de comandos muestra las combinaciones activas.

Paleta de comandos

Descubre y ejecuta comandos a través de una paleta con búsqueda difusa, similar a VS Code.

Tareas

Define tareas personalizadas para ejecutar comandos de shell, formateadores o scripts de compilación desde la paleta de comandos o el menú Tareas.

Solución de problemas

  • El terminal muestra una pantalla negra Pine usa un renderizador Metal por defecto. Si ves una pantalla negra, reinicia manteniendo pulsada la tecla opción, o ejecuta defaults write io.github.batonogov.pine PINE_DISABLE_METAL -bool YES para cambiar a CoreGraphics.
  • El completado o los diagnósticos LSP no funcionan Abre Ajustes > Lenguajes y verifica la ruta del ejecutable del servidor. Pine informa de los errores del servidor en la barra de estado.
  • Los archivos grandes son lentos Los archivos de más de 1 MB ofrecen desactivar el resaltado de sintaxis. Los de más de 10 MB se cargan progresivamente. Usa el minimapa para navegar por archivos grandes.
  • Formatear al guardar no se aplica Formatear al guardar requiere que la herramienta de formateo (p. ej. terraform, shfmt, prettier) esté en tu PATH. Instálala con Homebrew.
  • Compatibilidad con macOS 26 o 27 Pine tiene como objetivo macOS 26 (Tahoe). Si encuentras un problema específico de la plataforma, incluye la salida de sw_vers y xcodebuild -version en tu informe de error.
  • El agente no se detecta Pine detecta los agentes CLI compatibles por el nombre del proceso. Asegúrate de que el agente se ejecuta en un panel de terminal de Pine. El Terminal rápido aún no admite la detección de agentes.
