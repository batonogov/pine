Ayuda de Pine

Un editor nativo y enfocado para proyectos, código, terminales y Git en macOS.

Primeros pasos

1. Abre una carpeta

Selecciona Archivo > Abrir carpeta y elige el directorio que contiene tu proyecto.

2. Abre un archivo

Selecciona un archivo en la barra lateral o utiliza Apertura rápida para buscarlo por nombre.

3. Organiza el espacio de trabajo

Arrastra una pestaña al borde del editor para dividir un panel o a otra barra de pestañas para moverla.

4. Continúa trabajando

Pine restaura las ventanas del proyecto, las pestañas y la disposición de los paneles cuando vuelves.

Funciones rápidas esenciales

Abrir carpeta⇧⌘O
Apertura rápida⌘P
Símbolos⌘R
Buscar en el proyecto⇧⌘F
Ir a la línea⌘L
Guardar⌘S
Mostrar u ocultar terminal⌘`
Nueva pestaña de terminal⌘T
Vista previa de Markdown⇧⌘P
Cambiar rama de Git⇧⌘B

Consejo: los menús muestran todos los comandos disponibles y sus funciones rápidas actuales.

Editor, paneles y terminal

Paneles divididos

Las pestañas del editor y del terminal pueden moverse entre paneles compatibles. Suéltalas en un borde para crear una división.

Terminal integrado

Usa un terminal completo junto al código. Las pestañas abiertas conservan su historial.

Guardado seguro

Las pestañas sin guardar están protegidas antes de cerrarse. Guardado automático y Formatear al guardar están en Archivo.

Integración con Git

La barra lateral y el margen muestran cambios. El selector de ramas permite cambiar entre ramas locales.
