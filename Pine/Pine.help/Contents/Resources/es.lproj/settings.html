Ayuda de Pine

Ajustes y combinaciones de teclas

Ventana de ajustes

Pulsa Cmd+coma para abrir Ajustes. Configura los valores predeterminados del editor, el terminal, los servidores de lenguaje y la privacidad del agente.

Combinaciones de teclas personalizadas

Sobrescribe los atajos de teclado mediante archivos de combinaciones gestionados. La paleta de comandos muestra las combinaciones activas.

Paleta de comandos

Descubre y ejecuta comandos a través de una paleta con búsqueda difusa, similar a VS Code.

Tareas

Define tareas personalizadas para ejecutar comandos de shell, formateadores o scripts de compilación desde la paleta de comandos o el menú Tareas.
