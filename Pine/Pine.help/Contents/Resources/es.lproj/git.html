Integración con Git

Estado de archivos

La barra lateral muestra archivos modificados, añadidos y eliminados con indicadores de estado de color.

Marcadores de diff

Las líneas añadidas, modificadas y eliminadas aparecen como marcadores de color en el canal del editor.

Cambio de rama

Haz clic en el nombre de la rama en la barra de título o pulsa Cmd+Shift+B para cambiar entre ramas locales.

Vista de blame

Activa la vista de blame para ver la información de commit de cada línea: hash, autor, marca de tiempo y mensaje.
