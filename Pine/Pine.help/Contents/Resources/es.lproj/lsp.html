Ayuda de Pine

Servidores de lenguaje y diagnósticos

Inteligencia de código

Pine usa el Language Server Protocol para diagnósticos, completado, hover, ir a definición y renombrado.

Configurar servidores

Abre Ajustes > Lenguajes para activar, desactivar o configurar los ejecutables del servidor de lenguaje para cada idioma.

Panel de problemas

Consulta todos los diagnósticos del proyecto en un panel plegable. Navega por errores y advertencias con atajos de teclado.

Acciones de código

Haz clic en el indicador de diagnóstico del canal o usa el menú para aplicar correcciones rápidas y refactorizaciones.
