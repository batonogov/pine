Agenten-Posteingang und Workflows

Agenten-Posteingang

Wählen Sie Darstellung > Agenten-Posteingang oder drücken Sie ⇧⌘I, um Aufgaben aus allen geöffneten Projekten zu sehen. Der Posteingang erscheint an der Symbolleisten- oder Willkommens-Schaltfläche als Popover; klicken Sie außerhalb oder drücken Sie Escape, um ihn zu schließen. Wählen Sie eine Aufgabe mit den Pfeiltasten und drücken Sie Return, um exakt zu ihrer laufenden Sitzung zurückzukehren.

Private Mitteilungen

Legen Sie unter Einstellungen > Agenten fest, welche Warte-, Fehler-, Abschluss- und Prozessende-Ereignisse Sie benachrichtigen. Mitteilungen enthalten keine Prompts, Terminalausgaben, Token, absoluten Pfade oder Anbieterkennungen.

Wiederherstellung und Arbeitsbäume

Über das Kontextmenü einer Aufgabe können Sie eine unterstützte Anbietersitzung fortsetzen, eine neue Sitzung starten oder das Ziel kopieren. Isolierte Arbeitsbäume bleiben im Repository und werden nur bewusst bereinigt.

Abschlussberichte

Abgeschlossene Aufgaben trennen verifizierte Änderungen und Testergebnisse von Schlussfolgerungen, Unklarheiten und Angaben des Agenten, damit Sie das Ergebnis vor dem nächsten Schritt bewerten können.

Agent-Erkennung

Pine erkennt unterstützte CLI-Agenten im Terminal und zeigt deren Status mit Badges und Anzeigen an.

Aktivitäts-Panel

Sehen Sie eine Live-Ansicht der Agent-Aktivität: geänderte Dateien, ausgeführte Befehle und aktueller Status.

Agent-Verlauf

Überprüfen und machen Sie Agent-Änderungen rückgängig. Verifizierte Vorschauen zeigen genau, was sich ändert, bevor Sie es anwenden.

Datenschutz

Die Übergabe von Agent-Kontext ist optional und nur lesend. Pine sendet Ihren Code oder Ihre Terminalausgabe nirgendwohin ohne Ihr Zutun.

Wichtig: Pine wechselt nur zur exakten Generation einer laufenden Aufgabe und verweigert den Wechsel andernfalls sicher. Wiederhergestellte Aufgabenmetadaten bedeuten nicht, dass eine Anbietersitzung fortgesetzt wurde. Quick-Terminal-Sitzungen werden noch nicht von der Agent-Erkennung erfasst.

Pine erkennt Pi, Codex, Claude Code, OpenCode, Copilot, Aider, Gemini, Amp, Cursor Agent, Goose, Qwen Code und Crush anhand des exakten Programmnamens. Sofern die Matrix nichts anderes angibt, wird nur der Prozess erkannt.
