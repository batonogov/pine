Pine-Hilfe

Ein fokussierter nativer Editor für Projekte, Code, Terminals und Git unter macOS.

Erste Schritte

1. Ordner öffnen

Wählen Sie „Ablage“ > „Ordner öffnen“ und dann den Ordner Ihres Projekts.

2. Datei öffnen

Wählen Sie eine Datei in der Seitenleiste oder suchen Sie mit „Schnell öffnen“ nach ihrem Namen.

3. Arbeitsbereich anordnen

Ziehen Sie einen Tab an den Rand des Editors, um einen Bereich zu teilen, oder auf eine andere Tableiste, um ihn zu verschieben.

4. Weiterarbeiten

Pine stellt Projektfenster, Editor-Tabs und die Bereichsanordnung beim nächsten Start wieder her.

Wichtige Kurzbefehle

Ordner öffnen⇧⌘O
Schnell öffnen⌘P
Symbole⌘R
Im Projekt suchen⇧⌘F
Zu Zeile wechseln⌘L
Sichern⌘S
Terminal ein-/ausblenden⌘`
Neuer Terminal-Tab⌘T
Markdown-Vorschau⇧⌘P
Git-Branch wechseln⇧⌘B

Tipp: In den Menüs finden Sie alle verfügbaren Befehle und ihre aktuellen Kurzbefehle.

Editor, Bereiche und Terminal

Geteilte Bereiche

Editor- und Terminal-Tabs können zwischen passenden Bereichen verschoben werden. Am Rand entsteht ein neuer Bereich.

Integriertes Terminal

Verwenden Sie ein vollständiges Terminal neben Ihrem Code. Geöffnete Tabs behalten ihren Verlauf.

Sicheres Sichern

Ungesicherte Tabs werden vor dem Schließen geschützt. Automatisches Sichern und Formatieren finden Sie im Ablage-Menü.

Git-Integration

Seitenleiste und Rand zeigen Änderungen. Mit der Branch-Auswahl wechseln Sie zwischen lokalen Branches.
