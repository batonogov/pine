Fehlerbehebung

  • Terminal zeigt einen schwarzen Bildschirm Pine verwendet standardmäßig einen Metal-Renderer. Bei schwarzem Bildschirm starten Sie mit gedrückter Wahltaste neu, oder führen Sie defaults write io.github.batonogov.pine PINE_DISABLE_METAL -bool YES aus, um auf CoreGraphics zu wechseln.
  • LSP-Vervollständigung oder Diagnosen funktionieren nicht Öffnen Sie Einstellungen > Sprachen und prüfen Sie den Pfad zur Server-Ausführbaren. Pine meldet Serverfehler in der Statusleiste.
  • Große Dateien sind langsam Dateien über 1 MB bieten an, die Syntaxhervorhebung zu deaktivieren. Dateien über 10 MB werden fortschreitend geladen. Nutzen Sie die Minimap zur Navigation in großen Dateien.
  • Formatieren beim Sichern wird nicht angewendet Formatieren beim Sichern erfordert, dass das Formatter-Tool (z. B. terraform, shfmt, prettier) in Ihrem PATH liegt. Installieren Sie es über Homebrew.
  • macOS 26- oder 27-Kompatibilität Pine zielt auf macOS 26 (Tahoe). Bei einem plattformspezifischen Problem fügen Sie die Ausgabe von sw_vers und xcodebuild -version Ihrem Fehlerbericht hinzu.
  • Agent wird nicht erkannt Pine erkennt unterstützte CLI-Agenten anhand des Prozessnamens. Stellen Sie sicher, dass der Agent in einem Pine-Terminal-Bereich läuft. Quick Terminal unterstützt die Agent-Erkennung noch nicht.
