はじめに

1. フォルダを開く

「ファイル」>「フォルダを開く」を選択し、プロジェクトを含むディレクトリを選びます。

2. ファイルを開く

サイドバーでファイルを選ぶか、クイックオープンで名前から探します。

3. ワークスペースを整える

タブをエディタの端にドラッグして分割を作るか、別のタブバーにドラッグして移動します。

4. 作業を続ける

Pineはプロジェクトのウィンドウ、エディタのタブ、ペインのレイアウトを復元します。

エディタ、ペイン、ターミナル

分割ペイン

エディタとターミナルのタブは、同じ種類のペイン間で移動できます。端にドロップすると新しい分割が作成されます。

プレビューとピン留めタブ

サイドバーのファイルをクリックすると一時的なプレビュータブとして開きます。ダブルクリックまたは編集でピン留めできます。

検索と置換

Cmd+Fでファイル内検索。Cmd+Option+Fで検索と置換。プロジェクト全体の検索はCmd+Shift+Fです。

コード折りたたみとミニマップ

ガターの三角をクリックしてコードブロックを折りたたみます。ミニマップは「表示」メニューから切り替えられます。

Markdownプレビュー

Cmd+Shift+Pで、ソースのみ・レンダリング・並列Markdownプレビューを切り替えます。

シンボルナビゲーション

Cmd+Rを押すと、現在のファイル内の関数・クラス・構造体へジャンプします。

安全な保存

変更のあるタブは閉じる前に保護されます。自動保存と保存時フォーマットは「ファイル」メニューにあります。

セッションの復元

Pineはプロジェクトを再度開いたときに、タブ・ペインレイアウト・カーソル位置を復元します。

ターミナルとクイックターミナル

統合ターミナル

コードのすぐ隣でフル機能のターミナルを使えます。開いている間はスクロールバックが保持されます。

クイックターミナル

Ctrl+Option+Spaceで、どのアプリの上にも重なるフローティング型のドロップダウンターミナルを切り替えられます。

クリック可能なリンク

ターミナル出力の「ファイル:行」参照をCmd+クリックするとエディタで開きます。URLはシステムブラウザで開きます。

TUIアプリ

Vim、htopなどTUIアプリがネイティブに動作します。oh-my-zshやカラーテーマも完全にサポートされます。

Git連携

ファイルステータス

サイドバーに変更・追加・削除されたファイルが色付きのステータス表示で示されます。

差分マーカー

追加・変更・削除された行が、エディタのガターに色付きマーカーとして表示されます。

ブランチの切り替え

タイトルバーのブランチ名をクリックするか、Cmd+Shift+Bでローカルブランチを切り替えます。

Blame表示

Blame表示をオンにして、行ごとのコミット情報（ハッシュ・作成者・タイムスタンプ・メッセージ）を確認します。

言語サーバーと診断

コードインテリジェンス

PineはLanguage Server Protocolを利用し、診断・補完・ホバー・定義へ移動・名前変更を提供します。

サーバーの設定

「設定」>「言語」を開き、言語ごとにサーバー実行ファイルの有効化・無効化・設定を行います。

問題パネル

プロジェクト全体の診断を折りたたみ可能なパネルで確認します。キーボードショートカットでエラーや警告を移動できます。

コードアクション

ガターの診断インジケータをクリックするか、メニューからクイック修正やリファクタリングを適用します。

エージェント認識

エージェント検出

Pineはターミナルで動作する対応CLIエージェントを検出し、バッジとインジケータでステータスを表示します。

アクティビティパネル

エージェントのアクティビティをライブ表示します：変更されたファイル、実行されたコマンド、現在の状態。

エージェント履歴

エージェントの変更を確認・取り消しできます。検証済みプレビューが、適用前に変更内容を正確に示します。

プライバシー

エージェントへのコンテキスト受け渡しは任意かつ読み取り専用です。操作なしにコードやターミナル出力を送信することはありません。

CLIエージェントの互換性マトリクスと現在の制限事項を確認します。

設定とキーバインド

設定ウィンドウ

Cmd+カンマで設定を開きます。エディタの既定値、ターミナル、言語サーバー、エージェントのプライバシーを設定します。

カスタムキーバインド

管理されたキーバインドファイルでショートカットを上書きできます。コマンドパレットに有効な割り当てが表示されます。

コマンドパレット

VS Codeのように、あいまい検索可能なパレットからコマンドを探して実行できます。

タスク

カスタムタスクを定義し、コマンドパレットや「タスク」メニューからシェルコマンド・フォーマッタ・ビルドスクリプトを実行できます。

トラブルシューティング

  • ターミナルが黒い画面を表示する Pineは既定でMetalレンダラーを使用します。黒い画面になる場合は、optionキーを押しながら再起動するか、defaults write io.github.batonogov.pine PINE_DISABLE_METAL -bool YESを実行してCoreGraphicsに切り替えてください。
  • LSPの補完や診断が機能しない 「設定」>「言語」を開き、サーバー実行ファイルのパスを確認してください。Pineはサーバーのエラーをステータスバーに表示します。
  • 大きなファイルが遅い 1 MB超のファイルはシンタックスハイライトを無効にするか確認します。10 MB超のファイルは段階的に読み込まれます。大きなファイルの移動にはミニマップを使ってください。
  • 保存時フォーマットが適用されない 保存時フォーマットには、フォーマッタ（terraform・shfmt・prettier など）がPATHに存在する必要があります。Homebrewでインストールしてください。
  • macOS 26または27の互換性 PineはmacOS 26（Tahoe）を対象としています。プラットフォーム固有の問題が起きた場合は、バグ報告にsw_versとxcodebuild -versionの出力を含めてください。
  • エージェントが検出されない Pineは対応CLIエージェントをプロセス名で検出します。エージェントがPineのターミナルペインで実行されていることを確認してください。クイックターミナルはまだエージェント検出に対応していません。

もっとヘルプが必要ですか？

Pineのイシュートラッカーで問題を報告したり、改善を提案したりできます。
