Aide de Pine

Un éditeur natif et ciblé pour les projets, le code, le terminal et Git sur macOS.

Premiers pas

1. Ouvrez un dossier

Choisissez Fichier > Ouvrir le dossier, puis sélectionnez le répertoire de votre projet.

2. Ouvrez un fichier

Sélectionnez un fichier dans la barre latérale ou recherchez-le par nom avec Ouverture rapide.

3. Organisez l’espace de travail

Faites glisser un onglet vers le bord de l’éditeur pour créer un volet, ou vers une autre barre d’onglets pour le déplacer.

4. Reprenez votre travail

Pine restaure les fenêtres du projet, les onglets et la disposition des volets à votre retour.

Raccourcis essentiels

Ouvrir le dossier⇧⌘O
Ouverture rapide⌘P
Symboles⌘R
Rechercher dans le projet⇧⌘F
Aller à la ligne⌘L
Enregistrer⌘S
Afficher ou masquer le terminal⌘`
Nouvel onglet de terminal⌘T
Aperçu Markdown⇧⌘P
Changer de branche Git⇧⌘B

Astuce : les menus présentent toutes les commandes disponibles et leurs raccourcis actuels.

Éditeur, volets et terminal

Volets divisés

Les onglets d’éditeur et de terminal peuvent être déplacés entre des volets compatibles. Déposez-les sur un bord pour créer une division.

Terminal intégré

Utilisez un terminal complet à côté du code. Les onglets ouverts conservent leur historique.

Enregistrement sûr

Les onglets modifiés sont protégés avant leur fermeture. L’enregistrement et le formatage automatiques se trouvent dans Fichier.

Intégration Git

La barre latérale et la gouttière affichent les modifications. Le sélecteur permet de changer de branche locale.
