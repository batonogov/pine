Premiers pas

1. Ouvrir un dossier

Choisissez Fichier > Ouvrir le dossier, puis sélectionnez le répertoire contenant votre projet.

2. Ouvrir un fichier

Sélectionnez un fichier dans la barre latérale ou utilisez l'ouverture rapide pour le trouver par son nom.

3. Organiser votre espace de travail

Faites glisser un onglet vers un bord de l'éditeur pour créer une division, ou vers une autre barre d'onglets pour le déplacer.

4. Reprendre le travail

Pine restaure les fenêtres du projet, les onglets de l'éditeur et la disposition des volets à votre retour.

Éditeur, volets et terminal

Volets divisés

Les onglets d'éditeur et de terminal peuvent être déplacés entre les volets du même type. Déposez sur un bord pour créer une nouvelle division.

Aperçu et onglets épinglés

Un clic sur un fichier dans la barre latérale l'ouvre comme onglet d'aperçu temporaire. Double-cliquez ou modifiez-le pour l'épingler.

Rechercher et remplacer

Appuyez sur Cmd+F pour la recherche dans le fichier. Utilisez Cmd+Option+F pour rechercher et remplacer. La recherche dans tout le projet est Cmd+Shift+F.

Repliage de code et minimap

Cliquez sur un triangle de la gouttière pour replier des blocs de code. Activez ou désactivez la minimap depuis le menu Présentation.

Aperçu Markdown

Appuyez sur Cmd+Shift+P pour alterner entre source seule, rendu et aperçu Markdown côte à côte.

Navigation par symboles

Appuyez sur Cmd+R pour accéder aux fonctions, classes et structs du fichier courant.

Enregistrement sécurisé

Les onglets modifiés sont protégés avant la fermeture. L'enregistrement automatique et Formater à l'enregistrement sont disponibles dans le menu Fichier.

Restauration de session

Pine restaure vos onglets, la disposition des volets et les positions du curseur lorsque vous rouvrez un projet.

Terminal et Terminal rapide

Terminal intégré

Utilisez un terminal complet à côté de votre code. Les onglets de terminal conservent leur historique tant qu'ils restent ouverts.

Terminal rapide

Appuyez sur Ctrl+Option+Espace pour afficher ou masquer un terminal déroulant flottant au-dessus de n'importe quelle application.

Liens cliquables

Cmd+clic sur les références fichier:ligne dans la sortie du terminal pour les ouvrir dans l'éditeur. Les URLs s'ouvrent dans le navigateur système.

Applications TUI

Vim, htop et d'autres applications TUI fonctionnent nativement. oh-my-zsh et les thèmes de couleur sont entièrement pris en charge.

Intégration Git

État des fichiers

La barre latérale affiche les fichiers modifiés, ajoutés et supprimés avec des indicateurs de statut colorés.

Marqueurs de diff

Les lignes ajoutées, modifiées et supprimées apparaissent sous forme de marqueurs colorés dans la gouttière de l'éditeur.

Changement de branche

Cliquez sur le nom de la branche dans la barre de titre ou appuyez sur Cmd+Shift+B pour basculer entre les branches locales.

Vue blame

Activez la vue blame pour voir les informations de commit ligne par ligne : hachage, auteur, horodatage et message.

Serveurs de langage et diagnostics

Intelligence du code

Pine utilise le Language Server Protocol pour les diagnostics, la complétion, le survol, l'accès à la définition et le renommage.

Configurer les serveurs

Ouvrez Réglages > Langages pour activer, désactiver ou configurer les exécutables des serveurs de langage pour chaque langue.

Panneau Problèmes

Consultez tous les diagnostics du projet dans un panneau repliable. Naviguez parmi les erreurs et les avertissements avec des raccourcis clavier.

Actions de code

Cliquez sur l'indicateur de diagnostic dans la gouttière ou utilisez le menu pour appliquer des corrections rapides et des refactorisations.

Détection d'agents

Détection d'agents

Pine détecte les agents CLI pris en charge exécutés dans le terminal et affiche leur statut avec des badges et des indicateurs.

Panneau d'activité

Consultez une vue en direct de l'activité de l'agent : fichiers modifiés, commandes exécutées et état actuel.

Historique des agents

Examinez et annulez les modifications des agents. Les aperçus vérifiés montrent exactement ce qui changera avant l'application.

Confidentialité

Le transfert de contexte à l'agent est optionnel et en lecture seule. Pine n'envoie jamais votre code ni la sortie du terminal nulle part sans votre action.

Pine reconnaît Pi, Codex, Claude Code, OpenCode, Copilot, Aider, Gemini, Amp, Cursor Agent, Goose, Qwen Code et Crush par le nom exact de l’exécutable. Sauf indication contraire dans la matrice, seule la présence du processus est reconnue.

Consultez la matrice de compatibilité des agents CLI et leurs limitations actuelles.

Réglages et raccourcis clavier

Fenêtre Réglages

Appuyez sur Cmd+virgule pour ouvrir les Réglages. Configurez les valeurs par défaut de l'éditeur, le terminal, les serveurs de langage et la confidentialité de l'agent.

Raccourcis clavier personnalisés

Remplacez les raccourcis clavier via des fichiers de raccourcis gérés. La palette de commandes affiche les combinaisons actives.

Palette de commandes

Découvrez et exécutez des commandes via une palette à recherche floue, similaire à VS Code.

Tâches

Définissez des tâches personnalisées pour exécuter des commandes shell, des formateurs ou des scripts de compilation depuis la palette de commandes ou le menu Tâches.

Dépannage

  • Le terminal affiche un écran noir Pine utilise un moteur de rendu Metal par défaut. Si vous voyez un écran noir, relancez en maintenant la touche option enfoncée, ou exécutez defaults write io.github.batonogov.pine PINE_DISABLE_METAL -bool YES pour passer à CoreGraphics.
  • La complétion ou les diagnostics LSP ne fonctionnent pas Ouvrez Réglages > Langages et vérifiez le chemin de l'exécutable du serveur. Pine signale les erreurs du serveur dans la barre d'état.
  • Les gros fichiers sont lents Les fichiers de plus de 1 Mo proposent de désactiver la coloration syntaxique. Les fichiers de plus de 10 Mo se chargent progressivement. Utilisez la minimap pour naviguer dans les gros fichiers.
  • Formater à l'enregistrement ne s'applique pas Formater à l'enregistrement nécessite que l'outil de formatage (par ex. terraform, shfmt, prettier) soit dans votre PATH. Installez-le via Homebrew.
  • Compatibilité macOS 26 ou 27 Pine cible macOS 26 (Tahoe). Si vous rencontrez un problème spécifique à la plateforme, incluez la sortie de sw_vers et xcodebuild -version dans votre rapport de bogue.
  • L'agent n'est pas détecté Pine détecte les agents CLI pris en charge par leur nom de processus. Assurez-vous que l'agent s'exécute dans un volet de terminal Pine. Le Terminal rapide ne prend pas encore en charge la détection d'agents.
