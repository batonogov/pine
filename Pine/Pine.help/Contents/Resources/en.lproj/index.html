Get started

1. Open a folder

Choose File > Open Folder, then select the directory that contains your project.

2. Open a file

Select a file in the sidebar or use Quick Open to find it by name.

3. Arrange your workspace

Drag a tab to an edge of the editor to create a split, or to another tab bar to move it.

4. Keep working

Pine restores project windows, editor tabs, and pane layout when you return.

Editor, panes, and terminal

Split panes

Editor and terminal tabs can be moved between matching panes. Drop on an edge to create a new split.

Preview and pinned tabs

Clicking a file in the sidebar opens it as a transient preview tab. Double-click or edit to pin it.

Find and replace

Press Cmd+F for in-file search. Use Cmd+Option+F for find and replace. Project-wide search is Cmd+Shift+F.

Code folding and minimap

Click a disclosure triangle in the gutter to fold code blocks. Toggle the minimap from the View menu.

Markdown preview

Press Cmd+Shift+P to cycle between source-only, rendered, and side-by-side markdown preview.

Symbol navigation

Press Cmd+R to jump to functions, classes, and structs in the current file.

Safe saving

Dirty tabs are protected before closing. Auto Save and Format on Save are available in the File menu.

Session restore

Pine restores your tabs, pane layout, and cursor positions when you reopen a project.

Terminal and Quick Terminal

Integrated terminal

Use a full terminal beside your code. Terminal tabs keep their scrollback while they remain open.

Quick Terminal

Press Ctrl+Option+Space to toggle a floating drop-down terminal over any application.

Clickable links

Cmd+click on file:line references in terminal output to open them in the editor. URLs open in the system browser.

TUI apps

Vim, htop, and other TUI applications work natively. oh-my-zsh and color themes are fully supported.

Git integration

File status

The sidebar shows modified, added, and deleted files with colored status indicators.

Diff markers

Added, modified, and deleted lines appear as colored markers in the editor gutter.

Branch switching

Click the branch name in the title bar or press Cmd+Shift+B to switch between local branches.

Blame view

Toggle blame view to see per-line commit information: hash, author, timestamp, and message.

Language servers and diagnostics

Code intelligence

Pine uses the Language Server Protocol for diagnostics, completion, hover, go-to-definition, and rename.

Configuring servers

Open Settings > Languages to enable, disable, or configure language server executables per language.

Problems panel

View all project diagnostics in a collapsible panel. Navigate errors and warnings with keyboard shortcuts.

Code actions

Click the diagnostic indicator in the gutter or use the menu to apply quick fixes and refactors.

Agent awareness

Agent detection

Pine detects supported CLI agents running in the terminal and shows their status with badges and indicators.

Activity panel

See a live view of agent activity: files changed, commands run, and current working state.

Agent History

Review and undo agent changes. Verified previews show exactly what will change before you apply it.

Privacy

Agent context handoff is opt-in and read-only. Pine never sends your code or terminal output anywhere without your action.

Pine recognizes Pi, Codex, Claude Code, OpenCode, Copilot, Aider, Gemini, Amp, Cursor Agent, Goose, Qwen Code, and Crush by exact executable name. Recognition is process-only unless the matrix explicitly says otherwise.

View the CLI agent compatibility matrix and current limitations.

Settings and keybindings

Settings window

Press Cmd+comma to open Settings. Configure editor defaults, terminal, language servers, and agent privacy.

Custom keybindings

Override keyboard shortcuts through managed keybinding files. The command palette shows effective bindings.

Command palette

Discover and run commands through a fuzzy-searchable palette, similar to VS Code.

Tasks

Define custom tasks to run shell commands, formatters, or build scripts from the command palette or Tasks menu.

Troubleshooting

  • Terminal shows a black screen Pine uses a Metal renderer by default. If you see a black screen, relaunch with the option key held, or run defaults write io.github.batonogov.pine PINE_DISABLE_METAL -bool YES to switch to CoreGraphics.
  • LSP completion or diagnostics not working Open Settings > Languages and verify the server executable path. Pine reports server errors in the status bar.
  • Large files are slow Files over 1 MB prompt to disable syntax highlighting. Files over 10 MB load progressively. Use the minimap to navigate large files.
  • Format on Save is not applying Format on Save requires the formatter tool (e.g. terraform, shfmt, prettier) to be in your PATH. Install via Homebrew.
  • macOS 26 or 27 compatibility Pine targets macOS 26 (Tahoe). If you encounter a platform-specific issue, include sw_vers and xcodebuild -version output in your bug report.
  • Agent is not detected Pine detects supported CLI agents by process name. Make sure the agent is running in a Pine terminal pane. Quick Terminal does not yet support agent detection.
