Agent Inbox and workflows

Agent Inbox

Choose View > Agent Inbox or press ⇧⌘I to see tasks from every open project. Use the arrow keys to select a task and Return to route back to its exact live session.

Private notifications

In Settings > Agents, choose which waiting, failure, completion, and process-exit events can notify you. Notifications omit prompts, terminal output, tokens, absolute paths, and vendor identifiers.

Recovery and worktrees

Use a task's context menu to resume a supported vendor session, start a new session, or copy its objective. Isolated worktrees stay inside the repository and require deliberate cleanup.

Completion briefs

Completed tasks separate verified changes and test evidence from inference, ambiguity, and agent-reported narrative so you can judge the result before acting.

Agent detection

Pine detects supported CLI agents running in the terminal and shows their status with badges and indicators.

Activity panel

See a live view of agent activity: files changed, commands run, and current working state.

Agent History

Review and undo agent changes. Verified previews show exactly what will change before you apply it.

Privacy

Agent context handoff is opt-in and read-only. Pine never sends your code or terminal output anywhere without your action.

Important: Pine routes only to the exact live task generation and otherwise fails closed. Restored task metadata does not mean a vendor session resumed. Quick Terminal sessions do not yet participate in agent detection.

Pine recognizes Pi, Codex, Claude Code, OpenCode, Copilot, Aider, Gemini, Amp, Cursor Agent, Goose, Qwen Code, and Crush by exact executable name. Recognition is process-only unless the matrix explicitly says otherwise.
